## 分层适配要点

- **30 人以下（降本增效型）**：只保留 1 个场景，试点期即上线，砍掉深化期；ROI 用最保守口径
- **30-200 人（进步型）**：标准六段结构，2-3 个场景分期推进
- **200 人以上 / 央国企（战略型）**：必须补充「数据安全与合规」章节（等保要求、数据不出域方案、供应商退出机制），分期计划延长并加入「管理层汇报机制」

## 常见退回原因（自查）

1. 目标不可量化（「提升效率」无基线数字）
2. 场景设计没写「人在哪个环节审核」（全自动承诺是红线）
3. ROI 只给乐观值、假设不透明
4. 风险章节是套话，与该客户实际画像无关
