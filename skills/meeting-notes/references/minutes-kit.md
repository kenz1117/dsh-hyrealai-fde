# 会议纪要要点清单与追问话术（minutes-kit）

> 用法：按会议类型选用要点清单；行动项五要素缺任何一项，用追问话术现场补齐。

## 一、按会议类型的整理要点

### 调研访谈会（客户首次接触）
- 必记：痛点原话（不加工）、量化数字、组织架构与决策链信息
- 必问：还有谁必须访谈？下次访谈时间？
- 信号：一把手是否亲自参会、中层配合度

### 方案汇报会
- 必记：客户对每条方案的表态（接受 / 保留 / 反对 + 原因）、砍掉的方案及原因
- 必问：确认立项还需要什么材料？预算审批流程下一步？
- 信号：客户追问 ROI 细节 = 真意向；客户反复强调风险 = 顾虑未解

### 周例会 / 项目例会
- 必记：上期行动项逐条对账（完成 / 延期 + 原因）、本期里程碑变化
- 必问：延期项的新期限与补救措施
- 信号：同一行动项连续两期延期 = 升级给 FDE 处理

### 培训现场
- 必记：学员高频问题（原话）、操作卡点、负面情绪信号
- 必问：哪些岗位还没覆盖？
- 后续：高频问题提交知识库（submit_knowledge），纳入下期培训

## 二、行动项五要素核对表

| 要素 | 合格标准 | 不合格示例 |
|------|----------|------------|
| 事项 | 动词开头、可验证 | 「加强沟通」（不可验证） |
| 责任人 | 具体人名 | 「相关部门」「他们」 |
| 期限 | 具体日期 | 「尽快」「下阶段」 |
| 验收标准 | 第三方能判断完成与否 | 「基本完成」 |
| 依赖项 | 前置条件写明 | 隐含依赖未暴露 |

## 三、追问话术（要素缺失时）

- 缺责任人：「这件事落给谁推动？如果需要协调，谁有这个权限？」
- 缺期限：「我们定在几号前给结果？以什么事件为节点（下次例会 / 月底）？」
- 缺验收标准：「做到什么程度算完成？谁来确认？」
- 含糊表态：「您刚才说原则上同意，具体是同意哪几条？哪些还要再议？」

## 四、纪要质量自查清单

1. 结论是否在第一屏可见？（高管只看结论）
2. 每个行动项五要素是否齐全？
3. 上期行动项是否逐条对账（例会类）？
4. 是否有编造或脑补的内容？（模糊处必须标注待确认）
5. 敏感内容是否已剔除正文？
6. 与项目档案（阶段 / 里程碑）口径是否一致？
