# 决策规则速查 — 企业 AI 落地与 FDE 驻场方法论五件套

| 能力 | 一句话规则 |
|---|---|
| 四重九式驻场作业体系 | 把驻场全流程按四重九式标准化作业——每式有目标、动作、交付项与阻断性质量门禁，不过门禁不进下一式。 |
| SLP 现场落地路径与低风险入场 | 场景锁定（小、可度量、有权限）→跨界链接（隐性知识显性化）→试点验证（2–4 周数据说话），先验证再投入，无效几乎零损失。 |
| 企业 AI 成熟度诊断 | 用五层级（L1战略对齐→L5智能原生）+12题自诊断定位企业层级，配就绪度五维尽调与一票否决判断项目该不该接。 |
| L3→L4 跨越 90 天 Playbook | 跨 L3→L4 鸿沟的三个动作（选对切入点/建平台而非单点/同步调整组织考核）+ 90 天四阶段作战（诊断→底座→首个流程AI化灰度→组织适配）。 |
| FDE 能力模型与鉴别晋级 | 三栖能力模型（20%销售/30%产品/50%工程）+ 真 FDE 五条鉴别标准 + 三级进阶（L1应用/L2技能/L3架构，靠作品不靠笔试）+ 四步教练法。 |
| 经验蒸馏与产品化（服务商分水岭） | 试金石是「下一个项目能否从零开始」——砂石路→柏油路产品化双链路、智能积木一次优化多域复用、复用方法不复用数据的 IP 红线。 |
| 知识飞轮与组织级数据治理 | 四种数据分类绝不互相冒充、知识飞轮八步闭环（自动化止步于提案、合并必须人工审批）、Git 为唯一真相源。 |
| 中国式本体论（五层蛋糕 + 三体架构） | 五层蛋糕（价值→基建）+ 三体（主体/数体/智体）构成企业 AI 本体建模框架，价值与规则层先于技术。 |
| FDE+FDR 协同闭环（一次性部署已死） | 部署是起点不是终点——FDR 七环节承接持续迭代，效果衰减按数据漂移四分类归因，小样本迭代 48–72h 恢复。 |
| FDE/OPC/OPT 超级个体三剖面 | 怎么交付（FDE 职业角色）/怎么存在（OPC 法律实体）/怎么作战（OPT 能力放大）三问正交，先 OPT 后 OPC。 |
| FDE 本土化六大障碍风险矩阵 | 六障碍 P0/P1/P2 排序——人才供给与企业认知是生死线，IP 主权是「不紧迫但决定走多远」的暗线。 |
| 数字员工组织演进三阶段 | 超级个体（产能锁个人会话）→数字员工（团队化但人肉调度）→云上 Scrum（协议自组织，人只管目标与验收），按兜底项能否工程化判断升级。 |
| Agent 可控性设计（数字投手四组件） | 约束 Agent 自由度的四组件——经验（该做什么）/手脚（能做什么）/头脑（怎么选）/评测（做对没有），确定性交给工程。 |
| 数据闭环 1–10 与双 Loop | 基建解决 0→1、数据闭环解决 1→10——线上执行→分层评测→归因→补给→上线，走经验 Loop（策略）与手脚 Loop（失败轨迹 Skill 化）。 |
| AI Native 可靠交付四环节 | 项目理解（Code Docs/Graph/Rules）→需求理解（Spec 前置澄清）→可靠编码（TDD 链路幂等）→线上排障（TraceId 证据链），四环节各有沉淀资产。 |
| 上下文资产三件套（一个需求、一组事实） | 每个任务=上下文资产+执行环境+验证证据；验证发现的新事实必须回写沉淀，不回写就不算资产。 |
| 环境与验证驱动（Spec 约束/假设二分） | Coding 已近被解决，瓶颈在环境与验证——先测瓶颈再定投资；Spec 二分为约束（自动检查）与假设（开放迭代）。 |
| 人机分工与信任边界外移 | 执行权逐步交 AI，判断权与责任留在人；放权按「护栏是否先于信任到位」判断，不按「模型够强」判断。 |
| Agent 权限五原则与有效权限交集公式 | 有效权限 = 用户权限 ∩ Agent 能力上限 ∩ 平台策略 ∩ 委托范围 ∩ 运行时约束；意图与授权分离，授权三态含 Challenge。 |
| Guardrail 三态协议（PASS/BLOCKED/UNKNOWN + Evidence） | 门控三态 PASS/BLOCKED/UNKNOWN，UNKNOWN 不当 PASS、无证据不放行；Spec 固定版本、ChangeSet 比对失效机制。 |
| secrets 永不物化（Credential Broker 模式） | 真实凭证绝不进上下文/进程/沙箱/快照/日志——代理调用＞短期凭证注入＞长期凭证（仅白名单）。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
