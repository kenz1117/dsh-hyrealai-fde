# 健康信号判定阈值与干预动作库（health-kit）

> 用法：五项信号逐项对照判定；按风险分级选用干预动作。阈值为通用口径，可按项目实际校准。

## 一、五项信号判定表

### 1. 节奏信号（项目还活着吗）
| 结论 | 判定 |
|------|------|
| 正常 | 最近 2 周内有里程碑更新或正式会议纪要 |
| 观察 | 2-4 周无更新 |
| 预警 | >4 周无更新，或连续两次约会议被推迟 |

### 2. 进度信号（里程碑是否可信）
| 结论 | 判定 |
|------|------|
| 正常 | 里程碑按期完成，阶段停留时长符合分期计划 |
| 观察 | 单个里程碑延期 ≤2 周且有新期限 |
| 预警 | 同一里程碑二次延期，或延期 >2 周无新期限 |

### 3. 交付信号（上游物料齐不齐）
| 结论 | 判定 |
|------|------|
| 正常 | 当前阶段交付物齐备且版本在推进 |
| 观察 | 交付物缺失但已排期 |
| 预警 | 进入某阶段但其上游交付物从未产出 |

### 4. 组织信号（人还在支持吗）
| 结论 | 判定 |
|------|------|
| 正常 | 一把手近 1 个月有实质参与（决策/露面），行动项按期闭环 |
| 观察 | 一把手缺席连续 2 次重要会议；行动项偶发延期 |
| 预警 | 对接人更换且无交接、行动项连续两期延期、客户开始绕开流程 |

### 5. 数据信号（用起来了吗）
| 结论 | 判定 |
|------|------|
| 正常 | 关键指标连续两期增长或稳定达标 |
| 观察 | 指标波动但整体持平 |
| 预警 | 推广期指标连续两期下降，或「上线即峰值、此后归零」曲线 |

## 二、根因四归因

| 归因 | 典型表现 | 首选干预方向 |
|------|----------|--------------|
| 节奏 | 无人推动、会议约不上 | 重立节奏：固定例会 + 里程碑责任到人 |
| 数据 | 指标差、没人用 | 场景回炉：换场景或降低使用门槛 |
| 组织 | 领导不管、中层抵触 | 升级汇报：一把手一对一 + 标杆部门示范 |
| 范围 | 需求膨胀、验收扯皮 | 收缩范围：砍回一个场景一期交付 |

## 三、干预动作库

### 黄灯（FDE 自行处理，2 周内复查）
1. 与对接人一对一沟通，定位卡点（用访谈四连问：频率/人群/现状/损失）
2. 重发或收紧行动项清单（五要素齐全）
3. 排一次有客户方负责人出席的 30 分钟站会
4. 产出一份轻量干预纪要（meeting-notes），下次检查时对账

### 红灯（升级处理，1 周内启动）
1. 准备一页纸红灯报告（事实 + 影响 + 两个可选方案），约客户决策层
2. 项目范围收缩提案：保住已验证的场景，暂停长尾需求
3. 内部求助：申请专家资源或高层出面（写清需要什么、为什么、期限）
4. 复盘基线：确认是否触发生命周期决策（暂停 / 缩期 / 终止），由决策层拍板，不自行宣布

## 四、批量巡检输出格式

```
【巡检范围】{N} 个项目（{日期}）
【红灯】{项目名列表}——每个一句主因 + 建议动作
【黄灯】{项目名列表}——一句观察项
【绿灯】{数量} 个（不展开）
【本次与前次对比】新晋红灯 / 解除预警 项目点名
```
